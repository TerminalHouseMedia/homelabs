# Knowledge checks

Practice questions; completion is not inferred from deployment.

1. Why does HTTP 200 not establish WebGL rendering?
2. Which parts render on the VM versus the desktop GPU?
3. Why reject ambiguous headline geography?
4. How does source publication age differ from collection age?
5. Why is a country reference point not a verified impact site?
6. What does a nearby data-center point count establish, and what does it not?
7. Why retain original source URLs and timestamps?
8. How do parent origin and child-frame checks differ?
9. Why render text before globe readiness?
10. Which failure states should remain explicit when a provider is unavailable?

## Practical tasks

1. Run the synthetic tests, trace one accepted and one rejected event, and explain every decision.
2. In an isolated preview, simulate feed failure and missing map readiness, then restore the working state and record the evidence.
